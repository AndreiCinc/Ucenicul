# Skill 39 — Evidence Packager

## Goal
Package testing evidence into concise, reviewable artifacts.

## Required outputs
- workflow run records
- chain run records
- connector patch records
- compact workflow contract summaries
- remediation logs
- final summary
- snapshot index
- DB evidence index
- mission state ledger

## Rule
Evidence should be sufficient for a successor operator to resume or audit without replaying the whole mission.
