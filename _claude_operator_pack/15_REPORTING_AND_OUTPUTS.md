# 15_REPORTING_AND_OUTPUTS

## Mandatory run artifacts
- `STANDARDIZATION_DECISION.md`
- `INVENTORY_CLASSIFICATION.md`
- `CANONICALITY_DECISION.md`
- `RUN_QUEUE.md`
- `GLOBAL_RUN_SUMMARY.md`

## Mandatory per-workflow artifacts
- `WORKFLOW_RUN_RECORD__<WF>.md`
- `REMEDIATION_PASS_LOG__<WF>__P<n>.md`
- `QUARANTINE_NOTE__<WF>.md` when needed

## Final report format
For each workflow state:
- inspected
- classified
- remediated
- re-audited
- final verdict
- remaining gaps
- sensitive exclusions
- skills used
