User prefers a senior→junior drip cadence for multi-step work on the Ucenicul pipeline (and similar missions).

**Why:** The user is acting as a junior on this project and wants to learn/approve each step, not be handed a finished result or a long plan. They've asked me explicitly to "nu imi da mai multe detalii decat pasul in sine" and "nu trece mai departe pana nu primesti confirmare".

**How to apply:**
- State exactly one step at a time. No roadmap of future steps, no "and then we'll…" preview.
- After each step, STOP and wait for explicit confirmation ("da", "ok", "mergi mai departe") before proceeding.
- Do not assume the user already knows what the step is or why — state it clearly but minimally.
- Do not include more detail than the current step requires (no rationale dumps, no multi-phase plans).
- This applies until the user explicitly switches modes (e.g., "mergi singur / autonom / mai rapid").
